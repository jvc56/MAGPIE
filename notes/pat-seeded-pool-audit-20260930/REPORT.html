PAT + blocking + setup: exploratory nomination audit

PAT contributes new candidates, but this audit provides little evidence that replacing static nominations improves the best available reference move. It does not measure which pool a 15-second sim selects from more effectively.

We audited the existing 1,200 general positions and 400 late/ahead positions with current CSW24 and prior CSW24_hsp PAT models. Shared sources: top 25 by static + wide blocking adjustment, top 25 by static + wide setup adjustment, and up to five exchanges within 35 static points. The base source is top 25 no-PAT static or top 25 PAT. Counts remain adaptive. Earlier raw-signal extras are omitted from both pools.

“Best” means the maximum estimated win probability among available moves in the previously completed 60-second four-ply references. Those references used no-PAT static rollouts. No new simulations were run; no p-value or strength claim follows from these selected maxima. Current CSW24 adds six moves outside reference coverage across three general positions, so the general comparison is incomplete there.

For current CSW24, general position 150 gains SPRED (+0.159 percentage points in covered best); position 486 loses SERINGa (−0.194 points). The targeted late/ahead sample retains the same best reference value at every position. CSW24_hsp shows similar overlap and no advantage in the targeted sample.

A decisive follow-up would compare the two adaptive pools with 15-second selection sims, preserve no-PAT static rollouts, add references for uncovered nominees, and include equal-count controls. Keeping static + PAT nominations is also worth testing because replacement can drop a useful static candidate.

Provenance: protocol and validation; summary; per-position candidates. This exploratory audit is separate from the frozen completed studies.
